# Implementation Plan: Log files in the user's profile, with bounded rotation

Spec: [SPEC.md](../SPEC.md). Tasks: [todo.md](todo.md).

## Overview

Move Translator's log files from the install folder to `%LOCALAPPDATA%\Translator\Logs` and cap
them at 10 files of up to 10 MB. The change is almost entirely in the shipped `appsettings.json`.
The only new code is `LogFolder`, which reads the logs folder from the same configuration so the
new **Open logs folder** tray item can open it.

## Architecture Decisions

- **All log settings stay in `appsettings.json`** (SPEC → Decisions #3). `App.xaml.cs` and how
  Serilog is set up don't change.
- **The path is written once.** The tray item gets the folder from configuration through
  `LogFolder.Find`, never from a second hard-coded path.
- **Tests use the shipped `appsettings.json`**, not a copy of it. A test that builds its own
  config would still pass after someone breaks the real one.
- **The riskiest part comes first.** The design depends on `Serilog.Settings.Configuration`
  expanding `%LOCALAPPDATA%`, which the package doesn't document. T1 proves it with a real log
  file before anything else is built on it.

## Risks and Mitigations

| Risk | Impact | Mitigation |
|---|---|---|
| `%LOCALAPPDATA%` isn't expanded, and Serilog writes to a folder literally named `%LOCALAPPDATA%` under the exe folder | High | T1's first test writes a real file and checks where it lands. If the test fails, stop and ask. Moving the path into C# is a Boundaries "ask first" |
| Tests change `LOCALAPPDATA` for the whole test process, which could affect other tests running in parallel | Med | Put the logging tests in a collection with `DisableParallelization = true`, and restore the variable in `Dispose`. Other tests don't read `LOCALAPPDATA`. `UserSettingsFile` uses `%APPDATA%`, through `GetFolderPath` |
| The size-roll test hard-codes which `WriteTo` entry is the File sink, and breaks when the entries are reordered | Low | Find the File sink's index by `Name` before building the in-memory override key |
| `Resources.Designer.cs` isn't regenerated by `dotnet build` | Low | Add the property by hand, as was done for `OpenSettingsFolder`. `ResourcesTests` fails if it's missing |
| Serilog skips any event bigger than `fileSizeLimitBytes`, so the 1 KB test could write nothing | Low | Use short messages, about 100 bytes, and check that at least one file exists |
| Existing users' old `log*.txt` files stay in the install folder | Low | Accepted in the spec. Say so in the release notes |
